# AdminForge

AdminForge is the neutral Angular admin starter kit extracted from the reusable Core developed in AdminComeMiVesto.

## Current phase

SK.5.1 — neutral repository bootstrap.

This repository intentionally starts without Firebase, ComeMiVesto domain features, backend endpoints, authentication adapters, affiliate catalog, outfits, reports or application branding.

## Run

```bash
npm install
npm start
```

## Build

```bash
npm run build -- --configuration development
```

## Extraction plan

- SK.5.1 neutral Angular shell
- SK.5.2 canonical Core + styles
- SK.5.3 demo providers/adapters
